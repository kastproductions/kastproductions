# Signed off: a white page, ink, one signature blue, and no drawn pictures

The site drops the Neo Mirai world of ADR-0006. On 2026-11-20 the owner said the site looked generated and the drawn SVG scenes looked poor, and chose this direction from three proposals. The gold paper, the serif body, the mono caps labels, the numbered sections and the uppercase display headings are all common traits of generated pages, and the scenes were the weakest part of the site. The new direction comes from what the company sells: an agent whose outward actions wait for a named person to approve them. The page is cool white with blue-black ink. One fountain-pen blue marks the places a person acts: the primary button, a link that leads on, and the approval gate. One family, Schibsted Grotesk, sets every word in sentence case, and IBM Plex Mono sets only the strings a machine wrote. The site draws no illustrations and no ornaments. Where a page needs a picture, it shows what the agent makes, built in HTML and labelled "Example": the approval message in the home page hero, the run record on the product page, and the example run on the backlog page. The export suite fails a page that holds an SVG other than an icon. The single light theme stays, for the reason ADR-0006 gave: a dark version is a second design, not a setting.
