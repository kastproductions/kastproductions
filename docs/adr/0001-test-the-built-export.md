# Test the built export, not the source

The site is a static export, and what matters is what a crawler, an unfurl scraper and the analytics tracker read from the files in `out/`. Next.js merges metadata shallowly, so a page that declares its own `openGraph` object silently loses the inherited image: the metadata object looks correct while the built page unfurls blank, and a test over the object passes through the fault. The suite therefore has one seam, the export: `bun run test` builds first, every test reads files from `out/`, and no test imports a page component, a metadata object or a route handler. The price is a build before every run and no unit-level pinpointing; the gain is that a green suite means the emitted site is right. A route list that follows the page records keeps the suite covering a new page with no test edit.
