# Neo Mirai, light only, without its Japanese content

The site takes its visual world from Impeccable's Neo Mirai reference (impeccable.style/neo-mirai): warm gold paper with a faint grid and grain, ink, gold, a red sun, night teal, Chakra Petch for display, Zen Old Mincho for body text, Azeret Mono for labels, a stamp seal, and golden illustrated scenes, which we draw by hand as SVG. It replaces the paper, ink and coral of ADR-0005, but keeps that ADR's Tailwind and shadcn/ui: only the tokens and the components that draw them change. We took the system and left the place. The reference is a Tokyo conference, so it has a vertical Japanese poem, kanji and Mount Fuji. A Vilnius company that shows Tokyo scenery gives the reader a new question to ask, so the scenes show a future Vilnius and teams at work, and no Japanese text goes on the page. The reference has a light theme only, and a dark version of gold paper is a second design, not a setting. So dark mode goes, and the night-teal bands give contrast where a section needs it. A reader whose system asks for dark mode gets the light page.
