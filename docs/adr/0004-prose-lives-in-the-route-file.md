# Prose lives in the route file unless a kind of page shares its markup

`src/app/content.ts` holds every fact the copy carries and the page records, and it holds the prose of a page only when several pages print that prose through one component: the five job pages are records hung off their jobs and drawn by `src/components/job-page.tsx`, and a product page is drawn from the catalogue by `src/components/product-page.tsx`. A page of which there is one, which is each legal page, the explainer, the channel page, the about page and the contact page, keeps its prose in its own route file and takes from `content.ts` only the facts and the words other pages link it with. The obvious alternative, all copy in the content module, would have made that module the site and left each route file a shell around strings it cannot read. So a second explainer or a second channel page is a record and a route file, and the prose moves onto a record with shared markup when a third of that kind exists.
