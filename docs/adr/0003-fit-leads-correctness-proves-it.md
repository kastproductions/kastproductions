# Fit leads, and correctness is how we prove it

The standing agents line has three true claims, and a page can only lead with one. Fit says the agent matches how this company works. Convenience says the team reaches it by name in Slack or Teams, where they already are. Correctness says we wrote down what right means for that agent and hold it there.

The order is fit, then convenience, then correctness. Fit is the promise, because a generic agent has never been told what this company's correct is and so cannot be held to it. Convenience comes second because an agent nobody opens is worth nothing however well it fits. Correctness sits under both as the mechanism: the eval suite, the approval gates, the named engineer, the monthly report and the spend cap.

Fit is the company promise rather than one line's. Backlog runs proves it inside the client's repository and CI. Standing agents proves it by shaping an agent to the client's workflow.

## Consequences

Correctness was the headline for one round before fit displaced it. Anyone editing this copy should keep the mechanism as evidence for the promise and resist promoting it back to the headline, where it reads as a quality process rather than a reason to buy.

We never characterise what other companies sell. The page describes the generic product a reader has already seen demonstrated, which is a claim they can check for themselves, and leaves competitors unnamed.
